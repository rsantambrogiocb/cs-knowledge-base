# Relational model
It's important to understand that the **relational model is all about tables**. The output of any join is another table. The output of a query is a table. Single columned lists are tables.

# Subsets of SQL language
- **DDL (Data Definition Language)**: operations on the database such as CREATE, ALTER, and DELETE object.
- **DML (Data Manipulation Language)**: access and manipulate data; it helps to insert, update, delete and retrieve data from the database.
- **DCL (Data Control Language)**: allows to control access to the database, for example granting or revoking permissions.
