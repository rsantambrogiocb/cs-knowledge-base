# Python

### Introduction
Python is a **high-level, interpreted, general-purpose programming language**; being a general-purpose language allow to use it to build almost any type of application with the right tools/libraries. Interpreted language means that **executes each statement line by line**, running directly from the source code with no intermediary compilation step.

It supports objects, modules, threads, exception-handling, and automatic memory management which help in modelling real-world problems and building applications to solve these problems.

Python is a **dynamically typed language**, hence the type-checking is done on the fly during execution. Anyway it is a strong typed language, and for this don't allow "type-coercion" (implicit conversion of data types).

#### Style guide
PEP stands for Python Enhancement Proposal. A PEP is an official design document providing information to the Python community. PEP 8 is especially important since it documents the style guidelines for Python Code.
